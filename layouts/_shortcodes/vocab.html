{{- /* {{< vocab >}} — a vocabulary table. {{< vocab >}} der Bahnhof | station | Wir treffen uns am Bahnhof. die Fahrkarte | ticket | Ich kaufe eine Fahrkarte. {{< /vocab >}} Three columns: target term, gloss, example. Pipe-separated because an author types this between other prose and a YAML block would break the flow. ACCESSIBILITY — per-column `lang`, and this is the substance of the shortcode rather than a detail. A vocabulary table is the one place on the page where two languages sit in adjacent cells, so a screen reader that treats the whole table as one language reads the target terms in the wrong voice — German phonology applied to French words, which is not merely wrong but unusable for the learner who most needs it. The target column carries the course's target_language, the gloss column the chrome language. Headers are , so a cell announced out of order still says which column it belongs to. */ -}} {{- $target := site.Params.targetLanguage | default site.LanguageCode -}} {{- $chrome := site.Params.chromeLanguage | default "de" -}} {{- $rows := split (trim .Inner "\n") "\n" -}} {{- range $rows }} {{- $c := split . "|" }} {{- if ge (len $c) 2 }} {{- end }} {{- end }}
